# Asset-class universes for VCP cross-asset backtests (commodities / FX futures /
# country indices). One full Bloomberg security per line (yellow key included) --
# these are NOT bare equity tickers; scripts/fetch_assets_snapshot.py fetches them
# as-is and caches under the same string as the framework symbol.
#
# Spot FX (Curncy BGN) is deliberately absent: no PX_VOLUME -> the session's
# all-fields row filter returns "no data", and VCP's volume gates couldn't fire
# anyway. FX exposure comes via CME currency futures generics (real volume).
#
# Roll caveat (futures generics): plain generics splice contracts with price
# jumps at roll, which can fake breakouts/stops. If your terminal's GFUT default
# is set to a back-adjusted roll (e.g. ratio), the API returns adjusted series --
# set it BEFORE fetching, and note the setting in the run's Evidence.
